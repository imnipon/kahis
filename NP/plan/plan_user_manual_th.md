# คู่มือผู้ใช้ Plan Module (ภาษาไทย)

ไฟล์อ้างอิงหน้าจอ: `plan_editor.html`  
เอกสารเทคนิค: `plan_manual.md` · `for_dev_plan.md`

---

## 1. Plan คืออะไร

**Plan** คือแผนงานที่สัตวแพทย์กำหนดไว้ล่วงหน้าสำหรับสัตว์ป่วยใน exam card / HN — เช่น นัดตรวจเลือด, นัดติดตาม Vital & PE, หรือข้อความนัดหมายทั่วไป

ระบบแยกชัดระหว่าง:

| คำ | ความหมายสั้นๆ |
| :--- | :--- |
| **Schedule on** | วัน–เวลาที่ตั้งใจให้แผนนี้ “ถึงกำหนด” |
| **for-date** | วันที่ visit ที่กำลังดู (เช่น 05/08/2026) |
| **Record / Update** | เวลาบันทึก / แก้ไขล่าสุด (แสดงเป็น `วว/ดด/ปปปป ชม:นาที`) |
| **Status** | สถานะแผน: Plan · Done · Disable |
| **Inactive** | Schedule เลยวัน for-date แล้ว (คนละเรื่องกับ Disable) |

---

## 2. เปิดใช้งานอย่างไร

1. เปิด **Plan Editor** จาก badge  
2. เลือก visit tab ของ DVM/แผนก (mock: tab 1 ใช้งานได้)

เอกสารในหน้า: ปุ่มข้าง **View Logic/Rule** → **คู่มือผู้ใช้** · **Manual** · **For Dev** (เปิดไฟล์ `.md`)

## 3. หน้า Editor (บันทึกแผนของ visit นี้)

### 3.1 เพิ่มแผน

กด **+** เลือกประเภท:

- **Common Plan** — ข้อความแผน + template  
- **VPE Plan** — เลือกว่าจะตรวจส่วนไหนของ Vital & PE (ไม่กรอกค่า)  
- **Lab Plan** — เลือกรายการส่งตรวจ (เลือด / UA / Path ฯลฯ)  
- Form A / B — โครงว่างรอออกแบบ  

ทุกประเภทมี **Title** และ **Level** (เขียว / เหลือง / แดง)

### 3.2 บันทึกครั้งแรก (Draft → มี id)

1. กรอก Detail + ตั้ง **Schedule on** ใน Record Meta  
2. กด **Confirm** → ได้รหัสเช่น `PLAN-69001234-001` สถานะ **Plan**  
3. หลังมี id จะ **ลบไม่ได้** — ใช้ Disable แทน  

### 3.3 แก้ไขแผนที่มี id แล้ว

- แก้เนื้อหาแล้วกด **Apply** → อัปเดต Update Time  
- ปุ่ม **Disable / Enable (Plan)** สลับสถานะได้ (toggle) และจะ **อัปเดต Update Time** ทุกครั้ง  

ข้อความช่วย:  
`บันทึกแล้วมี id — ใช้ Disable / Enable (Plan) แทนการลบ →` อยู่**แนวเดียวกับปุ่ม** (ซ้ายของปุ่ม) เพื่อประหยัดพื้นที่แนวตั้ง  

**Plan Note** ใน editor / View ปรับความสูงกล่องตามเนื้อหาอัตโนมัติ

## 4. ตารางรวม plans

ใช้ดูภาพรวมทั้ง HN ไม่ผูกกับวัน filter ของ editor โดยตรง

### 4.1 คอลัมน์หลัก

Schedule On · ประเภท Plans · Title · Level · Plan Note · Status · DVM · Department · **Action** · Record/Update  

### 4.2 ปุ่ม Action

| ปุ่ม | ทำอะไร |
| :--- | :--- |
| **View** | เปิดหน้าต่างเฉพาะแผนนั้น (Detail + Meta) |
| **Change** | เปลี่ยนเป็น **Done** หรือกลับเป็น **Plan** เท่านั้น |

**Change ไม่มี Disable** — กันกดปิดแผนผิดพลาดจากตารางภาพรวม  
ถ้าต้องการ Disable ต้องเข้า **Editor** หรือ **View ในฐานะเจ้าของ**

### 4.3 สี/สไตล์แถว

- **Inactive (Schedule อดีต)** — ตัวอักษรจาง · ไปอยู่ท้ายตาราง  
- **Disable (สถานะ)** — ตัวอักษรจางทั้งแถวแบบเดียวกับ Inactive + badge Disable  

---

## 5. หน้าต่าง View

### ถ้าคุณเป็น DVM เจ้าของรายการ (และ exam card ตรง)

- แก้ Title / Level / รายละเอียดแผน / Schedule on / Plan Note ได้  
- กด **Apply** เพื่อบันทึก  
- สลับ **Disable ↔ Enable (Plan)** ได้  

### ถ้าไม่ใช่เจ้าของ

- อ่านอย่างเดียว ไม่มี Apply / Disable

## 6. ตัวอย่างเหตุการณ์ (Event) แบบต่างๆ

### Event A — สั่งตรวจเลือดวันเดียวกัน คนละหมอ เวลาเดียวกัน

- **วัน:** 06/08/2026  
- **08:00** DVM A สั่ง CBC + Chem  
- **08:00** DVM B สั่ง CBC + PLT (เวลาเดียวกัน คนละคำสั่ง)  

→ ในตารางจะเห็นสองแถววันเดียวกัน เวลาเดียวกัน แต่ DVM และ Title ต่างกัน  
→ เปิด View ของแถว DVM A (user ปัจจุบันเป็น A) จะแก้ได้ · แถวของ B อ่านอย่างเดียว  

### Event B — สั่งเลือดวันเดียวกัน แต่ต่างเวลา

- **06/08/2026 14:00** DVM A สั่ง UA + Chem renal  
- **06/08/2026 16:30** DVM B สั่ง Path cytology  

→ กรองตามวันเดียวกันแล้วยังเห็นลำดับเวลาเช้า→บ่าย  

### Event C — สั่ง VPE หลายช่วงในวันเดียว

- **07/08/2026**  
  - DVM A: 08:00 / 12:00 / 18:00 (สามช่วง)  
  - DVM B: 10:00 / 16:00 (สองช่วง)  

→ ใช้ดูว่าแผนติดตามซ้ำในวันเดียวถูกจัดเรียงตามเวลา (เก่า→ใหม่ในกลุ่ม Active)  

### Event D — ปิดแผนด้วย Disable (เจ้าของ)

1. เปิดแผนของตัวเองใน Editor หรือ View  
2. กด **Disable** → สถานะ Disable · Update Time เปลี่ยน · แถวในตารางจางลง  
3. กด **Enable (Plan)** อีกครั้ง → กลับเป็น Plan · Update Time เปลี่ยนอีก  

### Event E — เปิดแผนที่ถูก Disable จากตาราง (ไม่ใช่กด Disable ใหม่)

1. ในตารางหาแถว badge **Disable**  
2. กด **Change → Plan** (ถ้าแถวไม่ใช่ Inactive ตาม Schedule)  
3. หรือเปิด **View** (ถ้าเป็นเจ้าของ) แล้วกด **Enable (Plan)**  

**ทำ Disable จาก Change ในตารางไม่ได้**  

### Event F — ทำเครื่องหมาย Done หลังทำงานเสร็จ

1. แผน Lab/Common ที่ทำครบแล้ว  
2. ในตารางกด **Change → Done**  
3. ถ้าต้องเปิดใหม่ → **Change → Plan**  

### Event G — Schedule เลยวันแล้ว (Inactive)

- แผนที่ Schedule on เป็นวันก่อน for-date (เช่น 01/08 เมื่อ for = 05/08)  
- ไปอยู่ท้ายตาราง · ป้าย Inactive · **Change ใช้ไม่ได้**  
- ถ้าต้องการให้กลับมา Active: เจ้าของเปิด View/Editor แก้ Schedule on เป็นวันนี้หรืออนาคต แล้ว Apply  

### Event H — Draft ยังไม่ Confirm

- แผนใหม่ใน rail แสดง Draft · ยังไม่มี id  
- ลบได้ด้วย **Delete** (มียืนยัน)  
- หลัง Confirm จะลบไม่ได้ ต้องใช้ Disable  

### Event I — คนละแผนกแต่เวลาเดียวกัน

- เช่น 08/08 09:00 ทั้ง Common ของ DVM A และแผนภาพวินิจฉัยของ DVM B  
→ ตารางแสดงความต่าง DVM/Department ชัด แม้เวลาตรงกัน

## 7. สรุปกฎสั้นๆ ที่ควรจำ

1. **Confirm** = ได้ id · **Apply** = แก้เนื้อหา  
2. **Disable** ทำได้ที่ Editor / View เจ้าของเท่านั้น · มี Enable กลับเป็น Plan  
3. **Change ในตาราง** = Done หรือ Plan เท่านั้น · ห้าม Disable  
4. **Inactive** = เลยวัน Schedule · ไม่ใช่สถานะ Disable  
5. วันที่บนจอเป็นรูปแบบ **วว/ดด/ปปปป ชม:นาที**  

---

## 8. คำถามที่พบบ่อย

**ถาม: กด Disable ผิดจากตารางทำไมไม่ได้?**  
ตอบ: ออกแบบให้ Disable ทำได้เฉพาะตอนเปิดแผนของตัวเอง (Editor/View) เพื่อลดการปิดแผนผิดจากภาพรวม HN  

**ถาม: Disable กับ Inactive ต่างกันอย่างไร?**  
ตอบ: Disable = ปิดใช้งานแผนโดยเจตนา · Inactive = วันที่ Schedule เลย for-date แล้ว  

**ถาม: ทำไม Update บางแถวว่าง?**  
ตอบ: ยังไม่เคยแก้หลังบันทึกครั้งแรก · พอ Apply / Disable / Change จะมี Update Time
