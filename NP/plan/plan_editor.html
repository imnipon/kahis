Plan Editor — Logic / Rule
สรุปสั้น · เอกสารเต็มใช้ปุ่ม .md ข้าง View Logic
1. Plans & Meta
  • แต่ละรายการใน Plans มี Detail + Record Meta เป็นชุดเดียวกัน (สลับรายการ = สลับทั้งชุด · มีตัวเชื่อม highlight กับบล็อกขวา)
  • ทุก form เริ่มด้วย Title และ Level Symbol
  • Schedule on เก็บทั้งวันและเวลา
  • เพิ่มซ้ำได้ด้วยปุ่ม +
  • Draft (ยังไม่มี id) → ปุ่ม Delete · ลบได้หลังยืนยัน · Confirm เพื่อบันทึก
  • Saved (มี id) → สลับ Disable ↔ Enable (Plan) ที่ editor / View ของเจ้าของ · อัปเดต Update Time · แก้เนื้อหาด้วย Apply
  • ตารางรวม: Action View · Change เป็น Done/Plan เท่านั้น (ห้าม Disable จากตาราง — กันกดผิดจากภาพรวม) · Inactive (Schedule) ห้าม Change
  • แถว status Disable แสดงตัวอักษรแบบ Inactive ทั้งแถว
  • ไม่ใช้ Go เข้า tab editor ตาม filter date — ตารางรวมข้ามวัน/ข้าม tab
  • เรียงเก่า→ใหม่ · ถ้า Schedule on (วันที่) < for-date → Inactive ท้ายตาราง · กลับ Active โดยแก้ Schedule on ≥ for-date
  • แสดงวันที่เป็น dd/mm/yyyy HH:mm
2. VPE Plan
  • เช็คว่าให้ตรวจ ฟิลด์ใด ของ Vital & PE (ครบ 47 ฟิลด์) — มี checkbox ระดับหัวข้อ section ด้วย
  • จัดกลุ่มตาม section เดียวกับโมดูล Vital & PE · ไม่กรอกค่าจริงใน Plan
3. Lab Plan (mock)
  • หัวข้อ รายการส่งตรวจตัวอย่างทางห้องปฏิบัติการ
  • กลุ่ม: Hematology (CBC, PLT…), Blood Chemistry (BUN, ALT…), UA, Path Lab (cytology, biopsy)
  • ยังไม่เชื่อมกับรายการ items จนกว่าจะมีระบบ order
  • รูปแบบ items มีแนวโน้มเปลี่ยนชัดเจนเมื่อเชื่อม order ในอนาคต
4. อนาคต — VPE จริง
  • Plans บางชนิดอาจย้ายไปเป็นส่วนของ VPE จริง ได้ เมื่อเลือก form ที่ตรงกับโมดูล Vital & PE (แสดงใน Detail ของทุก plan)
