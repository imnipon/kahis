Pet Note — Logic / Rule (ย่อ)

Pet Note = โมดูลระดับ HN (ไม่ผูก visit เดียว) · เปิดเมื่อเข้า HN

แท็บ & แหล่งข้อมูล

  • น้ำหนัก — อ่านอย่างเดียวจาก VPE · คอลัมน์ Process on · Wt (kg) · Note · DVM/User · Department · Created on · Last Update · User Update · เรียงตาม Process on (ว่าง = Created on) · บันทึกเพิ่มที่ VPE เท่านั้น
  • Vet Note / ประวัติแพ้ยา / Staff Note — เขียนใน Pet Note · Add/Edit ผ่าน modal · Level Symbol 3 สี · ตาราง: Record on · ข้อความ · Level · User · Department · Status · Update · Update by · Action
  • ประวัติวัคซีน — อ่านจาก Items tag vaccine, deworm · Note จาก TX label · คอลัมน์เหมือนผ่าตัด (ไม่มีแหล่ง) · Process on ว่างแสดง Created on โดยไม่ใส่ข้อความกำกับ
  • ประวัติผ่าตัด — อ่านจาก Items tag surgery · โครงคอลัมเท่าวัคซีน

สิทธิ์ Edit / Disable (โน้ต)

  • แก้หรือ Disable ได้เฉพาะ เจ้าของรายการ (User ที่บันทึก) หรือ Admin
  • Disable / Apply ตอนแก้ → stamp Last Update (= Update) และ User Update (= Update by)
  • ไม่เปลี่ยน User / Department เจ้าของเดิมตอนแก้
