# คู่มือผู้ใช้ — Hoof Health (ใบบันทึกปาดกีบ)

โมดูลสำหรับบันทึกการตรวจ / ปาดกีบสัตว์ใหญ่ (โค · กระบือ) ในระบบ KAHIS  
หน้าจอหลัก: `hoof_health_editor.html`  
เอกสารเทคนิคสำหรับนักพัฒนา: ปุ่ม **View Logic/Rule** ในหน้าจอ

---

## 1. โมดูลนี้ทำอะไร

ใช้บันทึกว่าสัตว์แต่ละตัว ในแต่ละรอบปาดกีบ (Process on)

| สิ่งที่บันทึก | รายละเอียด |
| :--- | :--- |
| **ขา (Limb)** | LF หน้าซ้าย · RF หน้าขวา · LH หลังซ้าย · RH หลังขวา |
| **พื้นที่ (Side)** | **Lateral** (นอก) · **Medial** (ใน) · **Interdigital** (ซอกกีบ) |
| **โซน (Zone)** | เลข 0–12 ตามแผนภาพกีบมาตรฐาน (FIGURE 1) |
| **Lesion** | รหัสรอยโรค **ต่อโซน** (โซนหนึ่งมีได้หลายรหัส) |
| **Treatment** | รหัสหัตถการ **ต่อพื้นที่** (ไม่แยกต่อโซนในรอบนี้) |
| **Normal trim** | ระบุว่าพื้นที่หรือทั้งขาปกติ ไม่มีรอยโรค |
| **รูปหลักฐาน** | แนบจากไฟล์หรือกล้อง (เก็บในเบราว์เซอร์เครื่องนี้) |

**โมเดลตัวเลขต่อขา:** (โซน 1–12 × Lateral + Medial) + Interdigital โซน 0 และ 10 = **26 จุดบันทึก (terms)** ต่อขา

ผลบนภาพผังกีบ

- **1 วงต่อ lesion** (ไม่ใช่ 1 วงต่อโซน)
- **ในวง** = โค้ด lesion เช่น `SU` · `WALL` · `DD`
- **ใต้วง** = เลขโซนที่บันทึก
- **สีตัวอักษร** ตามด้าน: น้ำเงิน = Lateral · ส้ม = Medial · เขียวน้ำทะเล = Interdigital
- **ขอบ/เงาฟ้า** รอบวง = มี Treatment ที่พื้นที่นั้น
- **ลากวง** ด้วยเมาส์หรือนิ้วเพื่อขยับตำแหน่งแสดงผลได้

## 4. แท็บสัตว์ — โครงสร้างหน้าจอ

แบ่งเป็น **3 คอลัมน์**: ผังกีบ (ซ้าย) · ระบุตำแหน่ง (กลาง) · Record Meta (ขวา)

### 4.1 ซ้าย — ผังกีบ (แสดงผล + ลากวง)

- พื้นหลังคือแผนภาพโซนมาตรฐาน (`claw_zones_chart.png`)  
- **คลิกเลือกโซนบนภาพไม่ได้** — ต้องเลือกที่บล็อกกลางเท่านั้น  
- เมื่อมีข้อมูล lesion จะวาดวงทับตำแหน่งโซน  
- **ลากวงบนภาพได้** เพื่อขยับตำแหน่งแสดงผล (ค่าเริ่มต้นอยู่ที่เลขโซนบนแผนภาพ)  
- ใต้ภาพมี 3 กล่องสรุปข้อความ: **Lateral · Medial · Interdigital** ของขาที่กำลังดู (เรียงซ้าย→ขวาตามนี้)

#### ความหมายวงบนภาพ

| สิ่งที่เห็น | ความหมาย |
| :--- | :--- |
| 1 วงต่อ lesion | แต่ละรหัสรอยโรคมีวงของตัวเอง · โซนเดียวมีหลาย lesion = หลายวง |
| ข้อความในวง | โค้ด lesion เช่น `SU` · `WALL` · `DD` (ยาว ≥4 ตัวจะย่อฟอนต์) |
| เลขใต้วง | เลขโซนที่บันทึก (เช่น `4` · `11`) |
| สีตัวอักษร | น้ำเงิน = Lateral · ส้ม = Medial · เขียวน้ำทะเล = Interdigital |
| เงา/ขอบฟ้ารอบวง | มีหัตถการ (Treatment) ที่**พื้นที่**นั้น |
| ไม่มีวง | ยังไม่มี lesion ที่โซนนั้น หรือเป็น Normal trim |

#### ความสัมพันธ์โซนกับวง (สำคัญ)

แม้เลือก lesion ได้อิสระทุกโซน **วงยังรู้ว่ามาจากโซนไหนเสมอ**

ลำดับจริงในการบันทึกคือ

1. เลือกขา → พื้นที่ → **โซน**  
2. ติดรหัส lesion ใต้โซนนั้น  
3. ระบบวาดวงที่จุดของโซนนั้น พร้อมแสดงโค้ดในวงและเลขโซนใต้่วง

ตัวอย่าง: เลือก Zone 11 แล้วกด `DD` → ได้วงที่ตำแหน่งโซน 11 · ในวงเขียน `DD` · ใต้่วงเป็น `11` · สีตามด้านที่เลือก

#### การลากวง

- ลากด้วยเมาส์หรือนิ้วบนวง  
- ตำแหน่งที่ลากจะถูกจำใน record นั้น (จนกว่าจะลบ lesion / Clear / Normal ทับ)  
- หลาย lesion ในโซนเดียวกัน: ตอนสร้างแรกจะวางเยื้องเล็กน้อยไม่ให้ทับกัน แล้วลากจัดเองได้  
- ค่าเริ่มต้นก่อนลาก = จุดเลขโซนบนแผนภาพ

### 4.2 กลาง — ระบุตำแหน่งและรหัส (จุดเดียวที่สร้างข้อมูล)

เรียงตามลำดับการทำงานจริงในคลินิก

#### 1) ขา (Limb)

กด **LF / RF / LH / RH** — ผังซ้ายและกล่องสรุปจะสลับตามขาที่เลือก

#### 2) พื้นที่ (Side)

เรียงปุ่ม: **Lateral (น้ำเงิน) → Medial (ส้ม) → Interdigital (เขียวน้ำทะเล)**

#### 3) โซน (Zone 0–12)

- กดเลขโซนที่ต้องการ  
- โซนที่**ไม่เกี่ยวกับ**พื้นที่ที่เลือกจะกดไม่ได้ (เช่น เลือก Lateral แล้วโซน 0/10 จะ disabled)  
- ปุ่มโซนที่กำลังเลือกเป็นสี**ฟ้าอ่อน**  
- โซนที่มี lesion อยู่แล้วมีกรอบแดงด้านในปุ่ม (marked)

| พื้นที่ที่เลือก | โซนที่ใช้ได้ |
| :--- | :--- |
| Lateral / Medial | 1–9, 11, 12 |
| Interdigital | 0, 10 |

#### 4) Lesion codes

เลือกรหัสรอยโรคของ**โซนที่กำลังเลือก** (กดซ้ำเพื่อเอาออก)

**เลือกได้อิสระทุกโซนที่เปิดใช้** — ไม่มีการบล็อกรหัสกับโซน

| สถานะปุ่ม | ความหมาย |
| :--- | :--- |
| สีเต็ม (แดง) = เลือกอยู่ | รหัสนี้อยู่ในโซนปัจจุบันแล้ว |
| ปุ่มจาง (dim) | โซนปัจจุบัน**ไม่ใช่ตำแหน่งที่พบบ่อย**ของรหัสนั้น — เป็นคำแนะนำเท่านั้น **ยังกดได้** |
| วางเมาส์บนปุ่มจาง | มีข้อความอธิบายว่าเลือกได้ แต่ไม่ใช่ตำแหน่งคลาสสิก |

ตัวอย่างทางคลินิก: Zone 11 (ผนังแกน) พบบ่อยกับ `WALL` · ถ้าใส่ `DD` ที่ Zone 11 ได้ (ปุ่มจาง) สำหรับเคสที่รอยโรคลาม

รหัสที่มีในระบบ (รอบนี้)

| โค้ด | ชื่อเต็ม | โซนที่พบบ่อย (คำแนะนำ) |
| :--- | :--- | :--- |
| TU | Toe Ulcer | 1 |
| TN | Toe Necrosis | 1 |
| WLD | White Line Disease | 1, 2, 3 |
| WLA | White Line Abscess | 2, 3 |
| SB | Sole Bruise / Hemorrhage | 4, 5 |
| SA | Sole Abscess | 4, 5 |
| SU | Sole Ulcer | 4 |
| HHE | Heel Horn Erosion | 6 |
| FR | Foot Rot / Interdigital Phlegmon | 0 |
| DD | Digital Dermatitis | 10 |
| WALL | Wall lesion | 7, 8, 11, 12 |
| COR | Coronary / Skin lesion | 9 |

#### 5) Treatment

เลือกรหัสหัตถการของ**พื้นที่ทั้งก้อน** (Lateral หรือ Medial หรือ Interdigital ของขานั้น) ไม่ใช่ต่อโซน

| โค้ด | ชื่อเต็ม |
| :--- | :--- |
| BLK | Wood block |
| WRP | Wrap / spray |
| TRIM | Therapeutic trim |

เมื่อพื้นที่นั้นมี treatment และมี lesion อย่างน้อยหนึ่งโซน → วง lesion ของพื้นที่นั้นจะมีเงาฟ้ารอบวง

#### 6) ระบุตำแหน่งว่าปกติ (Normal Trim)

| ปุ่ม | ความหมาย |
| :--- | :--- |
| **Normal trim (ขอบเขตที่เลือก)** | ตั้งพื้นที่ปัจจุบัน (Lat/Med/Inter ที่เลือก) เป็นปกติ · ล้าง lesion/tx ของพื้นที่นั้น |
| **Normal trim ทั้งขา** | ตั้งทั้ง 3 พื้นที่ของขาปัจจุบันเป็นปกติ |

กดซ้ำเมื่อเป็น Normal อยู่แล้ว = ยกเลิก Normal (กลับเป็นค่าว่างของขอบเขตนั้น)  
Normal **ไม่วาดวง**บนภาพ · แสดงในกล่องสรุปใต้ภาพเป็น `[N] Normal trim`

#### หลักฐานรูป

| ปุ่ม | พฤติกรรมโดยประมาณ |
| :--- | :--- |
| **Browse…** | เลือกไฟล์รูปได้ทุกเครื่อง (มือถือ / โน้ตบุ๊ก) |
| **เปิดกล้อง** | ใช้ `capture="environment"` · **มือถือ**มักเปิดกล้องหลัง · **โน้ตบุ๊ก**มักเป็นเลือกไฟล์หรือ webcam ตามเบราว์เซอร์ — ไม่การันตีว่าได้กล้องทุกเครื่อง |

รูปที่แนบเก็บใน record ของรอบนั้น (mockup เก็บในเครื่อง)

#### ปุ่มล้างข้อมูล (สีแดงจาง อยู่ตรงหัวข้อ)

| ปุ่ม | ผล |
| :--- | :--- |
| **Clear ข้อมูลขาที่เลือก** | ล้างทั้งขา (Lat + Med + Inter) รวมตำแหน่งวงที่ลากของขานั้น |
| **Clear ข้อมูลพื้นที่ที่เลือก** | ล้างเฉพาะ Lateral / Medial / Interdigital ที่กำลังเลือก |

### 4.3 ขวา — Record Meta

- ข้อมูลสัตว์: ชื่อ / ชนิด / เพศ / เลขหู  
- **Process on** — วันเวลาที่ทำหัตถการ (จำเป็น)  
- สัตวแพทย์ / แผนก (แสดงจากระบบ mockup)  
- โน้ตช่วยจำ  
- ปุ่ม **Confirm** (ครั้งแรก / draft) หรือ **Apply** (เมื่อแก้ของที่ Confirm แล้ว)

แถบเครื่องมือด้านบนแท็บสัตว์ยังมี

- Last Process On / Last Update / Owner  
- เมนูเลือก **Process on** ของ record เดิม  
- **+ Add new** สร้างรอบใหม่  
- **History** ดูประวัติของ HN นี้

## 5. การบันทึกและแก้ไข

### Confirm (บันทึกครั้งแรก / ยืนยัน draft)

1. เลือกขา · พื้นที่ · โซน · ใส่ lesion / treatment ให้ครบตามที่ตรวจพบ  
2. ตรวจ **Process on**  
3. กด **Confirm**  
4. สถานะเป็น `done` · มีประวัติใน Change Log  
5. ตำแหน่งวงที่ลาก (ถ้ามี) ถูกบันทึกพร้อม record

### Apply (แก้ไขหลัง Confirm แล้ว)

1. เปิด record เดิมจากรายการ **Process on**  
2. แก้ข้อมูล (รวมถึงลากวงใหม่)  
3. ปุ่มจะเปลี่ยนเป็น **Apply**  
4. กด Apply เพื่อบันทึกการแก้ไข (มี log แยกจากการ Confirm)

### หลายรอบต่อตัว

สัตว์หนึ่งตัวมีได้หลายครั้ง (หลาย Process on)  
เลือกดูรอบเก่า–ใหม่ได้จากเมนู **Process on** ด้านขวาบน  
กด **+ Add new** เพื่อสร้างรอบใหม่ (สถานะเริ่มต้นเป็น draft)

- ถ้าข้อมูลเละหรืออยากกลับชุดตัวอย่างล่าสุดจากไฟล์: เปิด **View Logic/Rule** → **Hard reset**  
- หรือใช้ปุ่มโหลดชุดตัวอย่างใหม่ตามที่ระบุใน Logic  
- งานจริงบน production จะบันทึกลงฐานข้อมูล KAHIS ผ่าน API (ยังไม่ใช่ขั้นตอนนี้)

## 10. ลำดับงานแนะนำในคลินิก

1. เลือก Owner → **แสดง**  
2. เปิดแท็บสัตว์ตามคิว  
3. ตั้ง / ตรวจ **Process on**  
4. เลือกขาที่กำลังยก / ตรวจ  
5. เลือกพื้นที่ (Lateral / Medial / Interdigital)  
6. เลือกโซน → ใส่ lesion → (ถ้าต้องการ) ลากวงให้ตรงจุดบนภาพ  
7. ใส่ treatment ของพื้นที่นั้น  
8. สลับขา / พื้นที่ / โซน จนครบ  
9. ใส่รูปหลักฐาน (ถ้ามี) → **Confirm**  
10. ถ้ากลับมาแก้รอบเดิมภายหลัง → **Apply**

## 11. คำถามที่พบบ่อย

**ถาม: ทำไมปุ่ม DD จางเมื่ออยู่ Zone 11 แต่ยังกดได้?**  
ตอบ: จาง = ไม่ใช่ตำแหน่งที่พบบ่อย · ระบบไม่ห้ามเลือก เพราะเคสจริงอาจลามได้

**ถาม: วงบนภาพรู้ได้อย่างไรว่าเป็นโซนไหน ถ้า lesion เลือกอิสระ?**  
ตอบ: อิสระหมายถึง “รหัสไหนก็ติดโซนไหนได้” ไม่ได้แปลว่าไม่มีโซน — คุณเลือกโซนก่อนเสมอ แล้ววงผูกกับโซนนั้น

**ถาม: Treatment ทำไมไม่โชว์เป็นวงแยก?**  
ตอบ: รอบนี้ treatment เก็บระดับพื้นที่ · แสดงเป็นเงาฟ้ารอบวง lesion ของพื้นที่นั้น

**ถาม: ลากวงแล้ว refresh หายไหม?**  
ตอบ: ถ้า Confirm/Apply แล้ว ตำแหน่งถูกเก็บใน record บนเครื่องนี้ · Hard reset จะล้างทั้งหมดรวมตำแหน่งที่ลาก

**ถาม: เปิดกล้องบนโน้ตบุ๊กไม่ได้?**  
ตอบ: ปกติบนโน้ตบุ๊กให้ใช้ **Browse…** หรือยอมรับ dialog เลือกไฟล์/webcam ตามเบราว์เซอร์
