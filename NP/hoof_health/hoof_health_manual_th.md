# คู่มือผู้ใช้ — Hoof Health (ใบบันทึกปาดกีบ)

โมดูลสำหรับบันทึกการตรวจ / ปาดกีบสัตว์ใหญ่ (โค · กระบือ) ในระบบ KAHIS  
หน้าจอหลัก: `hoof_health_editor.html`  
เอกสารเทคนิคสำหรับนักพัฒนา: ปุ่ม **View Logic/Rule** ในหน้าจอ

---

## 1. โมดูลนี้ทำอะไร

ใช้บันทึกว่าสัตว์แต่ละตัว

- ขาไหนมีปัญหา (หน้าซ้าย / หน้าขวา / หลังซ้าย / หลังขวา)
- อยู่ด้านไหนของกีบ (**Lateral** นอก · **Medial** ใน · **Interdigital** ซอกกีบ)
- โซนไหน (เลข 0–12 ตามแผนภาพกีบมาตรฐาน)
- เป็นรอยโรคอะไร (**Lesion**) และทำหัตถการอะไร (**Treatment**)

ผลบนภาพ: วงแดง = มีรอยโรคที่โซนนั้น · วงน้ำเงิน = มีการรักษาที่พื้นที่นั้น

---

## 2. เริ่มใช้งาน

1. เปิด **Hoof Health Module** จาก Explorer  
2. เลือก **Owner No.** (เจ้าของ / ฟาร์ม)  
3. กดปุ่มเขียว **แสดง**  
4. จะเข้าสู่หน้าทำงาน (แท็บตารางรวม + แท็บสัตว์)

ปุ่มด้านบนที่ใช้บ่อย

| ปุ่ม | ความหมาย |
| :--- | :--- |
| **คู่มือ** | คู่มือผู้ใช้ภาษาไทย (หน้านี้) |
| **View Logic/Rule** | กติกา / โครงสร้างข้อมูล สำหรับทีมพัฒนา |
| **FIG.1 Claw zones** | ดูแผนภาพโซนกีบ |
| **LOG Change Log** | ประวัติการ Confirm / Apply ทั้งฟาร์ม |
| **✕** | ปิดหน้าทำงาน กลับไปเลือก Owner |

---

## 3. แท็บตารางรวม

แสดงรายการสัตว์ของ Owner ที่เลือก ตามวันที่ **Last Process On**

- คลิกแถวสัตว์ → เปิดแท็บของตัวนั้น  
- เปลี่ยนวันที่ด้านบนเพื่อกรองรอบปาดกีบ

---

## 4. แท็บสัตว์ — โครงสร้างหน้าจอ

แบ่งเป็น 3 ส่วน

### ซ้าย — ผังกีบ (ดูอย่างเดียว)

- แสดงแผนภาพโซน + วงสีตามข้อมูลที่บันทึก  
- **คลิกเลือกโซนบนภาพไม่ได้** — ต้องเลือกที่บล็อกกลางเท่านั้น  
- ใต้ภาพมี 3 กล่องสรุป: **Lateral · Medial · Interdigital** ของขาที่กำลังดู

ความหมายวงบนภาพ

| สี | ความหมาย |
| :--- | :--- |
| วงแดง (ใน) | มีรหัสรอยโรคที่โซนนั้น |
| วงน้ำเงิน (นอก) | มีหัตถการที่พื้นที่นั้น และโซนนั้นมีรอยโรค |
| ไม่มีวง | โซนนั้นยังไม่มีการบันทึก lesion (หรือเป็น Normal) |

### กลาง — ระบุตำแหน่งและรหัส

เรียงตามลำดับการทำงาน

1. **ขา (Limb)** — LF / RF / LH / RH  
2. **พื้นที่** — Lateral → Medial → Interdigital  
3. **โซน** — กดเลขโซนที่ต้องการ (โซนที่ไม่เกี่ยวกับพื้นที่ที่เลือกจะกดไม่ได้)  
4. **Lesion codes** — เลือกรหัสรอยโรค (กดซ้ำเพื่อเอาออก)  
5. **Treatment** — เลือกรหัสหัตถการของพื้นที่นั้น  
6. **ทางลัด** — Normal trim (ขอบเขตที่เลือก / ทั้งขา)

ปุ่มล้างข้อมูล (สีแดงจาง อยู่ตรงหัวข้อ)

- **Clear ข้อมูลขาที่เลือก** — ล้างทั้งขาที่กำลังเลือก  
- **Clear ข้อมูลพื้นที่ที่เลือก** — ล้างเฉพาะ Lateral / Medial / Interdigital ที่กำลังเลือก

### ขวา — Record Meta

- ชื่อสัตว์ / ชนิด / เพศ / เลขหู  
- **Process on** — วันเวลาที่ทำหัตถการ  
- สัตวแพทย์ / แผนก  
- โน้ตช่วยจำ  
- ปุ่ม **Confirm** (ครั้งแรก) หรือ **Apply** (เมื่อแก้ของที่ Confirm แล้ว)

---

## 5. การบันทึกและแก้ไข

### Confirm (บันทึกครั้งแรก / ยืนยัน draft)

1. เลือกขา · พื้นที่ · โซน · ใส่ lesion / treatment ให้ครบ  
2. ตรวจ Process on  
3. กด **Confirm**  
4. สถานะเป็น `done` และมีประวัติใน Change Log

### Apply (แก้ไขหลัง Confirm แล้ว)

1. เปิด record เดิมจากรายการ **Process on**  
2. แก้ข้อมูล  
3. ปุ่มจะเปลี่ยนเป็น **Apply**  
4. กด Apply เพื่อบันทึกการแก้ไข (มี log แยกจากการ Confirm)

### หลายรอบต่อตัว

สัตว์หนึ่งตัวมีได้หลายครั้ง (หลาย Process on)  
เลือกดูรอบเก่า–ใหม่ได้จากเมนู **Process on** ด้านขวาบน  
กด **+ Add new** เพื่อสร้างรอบใหม่

---

## 6. ประวัติ

| ที่ | ดูอะไร |
| :--- | :--- |
| ปุ่ม **History** ในแท็บสัตว์ | ประวัติของสัตว์ตัวที่เปิดอยู่ |
| ปุ่ม **Change Log** ด้านบน | ประวัติทั้ง Owner / ฟาร์ม |

ตัวอย่าง action ใน log: `confirm` · `apply` · `new-record`

---

## 7. สีปุ่มพื้นที่ (จำง่าย)

- **Lateral** = น้ำเงิน  
- **Medial** = ส้ม  
- **Interdigital** = ม่วง  

กล่องสรุปใต้ภาพใช้สีชุดเดียวกัน

---

## 8. ข้อควรจำ (Mockup)

- หน้านี้เป็น **mockup สำหรับสาธิต UI**  
- ข้อมูลถูกเก็บในเบราว์เซอร์เครื่องคุณ (localStorage) — refresh แล้วยังอยู่  
- เครื่องอื่น / คนอื่น จะเห็นชุดตัวอย่างตั้งต้นของตัวเอง  
- ถ้าข้อมูลเละหรืออยากกลับชุดตัวอย่าง: เปิด **View Logic/Rule** → **Hard reset**  
- งานจริงบน production จะบันทึกลงฐานข้อมูล KAHIS ผ่าน API (ยังไม่ใช่ขั้นตอนนี้)

---

## 9. ลำดับงานแนะนำในคลินิก

1. เลือก Owner → **แสดง**  
2. เปิดแท็บสัตว์ตามคิว  
3. เลือกขาที่กำลังยก / ตรวจ  
4. เลือกพื้นที่ (Lateral / Medial / Interdigital)  
5. เลือกโซน → ใส่ lesion → ใส่ treatment  
6. สลับขา / พื้นที่ จนครบ  
7. ใส่รูปหลักฐาน (ถ้ามี) → ตั้ง Process on → **Confirm**  
8. ถ้ากลับมาแก้รอบเดิมภายหลัง → **Apply**
