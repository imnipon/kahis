Chapter 05 — Subjective & Systematic Examination, Assessment Data Entry

Assessment (Problem / Diagnosis Terms) — การลงข้อมูล Assessment

เข้าหน้านี้ผ่านปุ่มทางลัด Assessment ในหน้า Exam Card Editor (ดูบทที่ 3 Label C/G) ใช้บันทึกปัญหา/ข้อวินิจฉัย ทางคลินิกโดยอ้างอิงรหัสมาตรฐานสากล SNOMED CT (Veterinary Extension) และ SA-PDT บทนี้แบ่งเป็น 3 ส่วนตามหน้าจอ คลิกที่ภาพเพื่อดูขนาดจริง

📢 ประกาศ — อยู่ในระหว่างการพัฒนา

โมดูล Assessment นี้อยู่ในระหว่างการพัฒนาฐานข้อมูลมาตรฐาน (SA-PDT / SNOMED CT) และการวางแนวทางการลงข้อมูลต่อเนื่องของแต่ละปัญหา/ข้อวินิจฉัย เช่น การทำงานผ่านชุดข้อมูลเดียวกันเพื่อการอัปเดตสถานะของโรคในแต่ละ Exam card ถัดไป (ไม่ต้องสร้างรายการใหม่ซ้ำทุกครั้งที่มา follow-up) รายละเอียดขั้นตอนและหน้าจอในบทนี้อาจมีการปรับปรุงเพิ่มเติมตามความคืบหน้าของการพัฒนา

ส่วนที่ 1 — ค้นหาและเลือก Concept

กดปุ่ม 🔍 เลือก Concept ในฟอร์มกรอกรายละเอียด (ส่วนที่ 2) เพื่อเปิดหน้าต่างนี้

1 ช่องกรอกคำค้น Search

พิมพ์คำค้นอย่างน้อย 3 ตัวอักษร ระบบจะค้นในฐานคำศัพท์มาตรฐาน SA-PDT / SNOMED CT ให้ ด้านซ้ายมี checkbox กรองตาม Semantic Tag เช่น Disorder, Finding, Observable Entity, Organism, Procedure, Regime/Therapy, Situation, Specimen, Substance

2 รายการผลการค้นหา Results

รายการ concept ที่ค้นพบ แสดงชื่อ, คำอธิบายสั้น และรหัส SNOMED CT รายการที่เลือกจะไฮไลต์สีฟ้า และนำรายละเอียดไปแสดงในบล็อกขวา (Label 3)

3 รายละเอียด Concept ที่เลือก Detail

แสดงรายละเอียดของ concept ที่เลือก พร้อม:

  • Synonyms & Aliases — คำพ้องความหมายของ term นี้
  • Assessment Categories — หมวดหมู่ที่ term นี้สังกัดอยู่ พร้อมรหัส SNOMED CT
  • ปุ่ม "เลือก Concept นี้" — ยืนยันเลือก concept กลับไปที่ฟอร์มกรอกรายละเอียด

ส่วนที่ 2 — ฟอร์มกรอกรายละเอียดปัญหา (Add New PDT Concept)

1 Tab แสดง Exam card ที่เลือกทำ Assessment Exam Card Tab

แสดง Tab ของ Exam card ที่กำลังเพิ่ม/แก้ไขรายการ Assessment อยู่ (คล้ายรูปแบบ Tab ในหน้า Exam Card Editor)

2 รายการที่เลือกแล้ว (Selected Problem / Diagnosis Terms) Selected List

รายการปัญหา/ข้อวินิจฉัยที่เพิ่มไว้แล้วสำหรับ Exam card นี้ — 1 Exam card สามารถมีได้หลายรายการ (หลาย PDT) พร้อมกัน แต่ละรายการแสดง:

  • ชื่อ concept (เช่น Diarrhea, Gallstones)
  • Semantic tag (Disorder / Finding)
  • ตัวย่อประเภทปัญหา — Dx (Working Diagnosis) / Sign (Clinical Sign) / DDx (Differential) / RO (Rule Out)
  • สถานะ — Active / Pending / Resolved
  • ปุ่ม ✎ แก้ไข และ ✕ ลบรายการ
3 ค้นหา/เลือก Concept และ Required tag Concept + Required

ปุ่ม 🔍 เลือก Concept เปิดหน้าต่างค้นหา (ดูส่วนที่ 1) เมื่อเลือกแล้วชื่อ concept จะแสดงเป็น pill พร้อมปุ่ม × สำหรับล้างค่า

แถบ Required แสดงรายการที่ต้องกรอกให้ครบก่อนบันทึกได้ พร้อมเครื่องหมาย ✓ เมื่อกรอกครบ: Concept / Problem Note (กรอกอย่างน้อยหนึ่งในสองช่องนี้), Clinical Condition Category, Clinical Status, DVM, Dept

4 ฟิลด์รายละเอียดปัญหา Fields

ฟิลด์รายละเอียดของปัญหา/ข้อวินิจฉัยที่เลือก อ้างอิงมาตรฐาน SNOMED CT (VetSCT) ระบุรหัส Concept ID (SCTID) กำกับแต่ละตัวเลือกไว้ในตาราง:

5 ช่อง NOTE เสนอ term ใหม่ (ฟิลด์เดียวกับข้อ 11) Suggest Term

Label 5 ในภาพชี้ไปที่ช่อง หมายเหตุรายการ (Problem Note) ซึ่งเป็นฟิลด์เดียวกับข้อ 11 ในตารางฟิลด์ของ Label 4 — ใช้กรอกในกรณีค้นหา concept มาตรฐานไม่พบตามต้องการ หรือต้องการเพิ่มเติมเองโดยไม่ใช้ term จากมาตรฐาน แนะนำใส่ 1 term ต่อครั้ง ทางผู้ดูแลระบบจะรวบรวมข้อมูลนี้เพื่อพิจารณาแก้ไข เพิ่มเติม หรือแจ้งคำที่เหมาะสมจากฐานข้อมูลมาตรฐานสากลต่อไป

6 ปุ่มเก็บรายการ Append Problem

ปุ่ม + Append Problem ใช้เก็บรายละเอียดปัญหาที่กรอกไว้เข้าสู่รายการ Selected Problem / Diagnosis Terms (Label 2) ก่อนจะบันทึกลงฐานข้อมูลจริงอีกครั้งด้วยปุ่ม Confirm (Label 7)

กด ✎ ที่รายการใน Selected List (Label 2) เพื่อโหลดรายละเอียดกลับมาแก้ไขในฟอร์มนี้ แล้วกด Append Problem ซ้ำเพื่ออัปเดตรายการ

7 Record Meta, ปุ่ม Confirm และ Assessment Note Record Meta

ส่วนขวาสุดของฟอร์ม ประกอบด้วย:

  • DVM และ Department — อ่านอย่างเดียว ดึงอัตโนมัติจาก Exam card ที่เปิดอยู่
  • ปุ่ม Confirm — บันทึกรายการ Selected Problem / Diagnosis Terms ทั้งหมดของ Exam card นี้ลงฐานข้อมูลจริง
  • Assessment Note (สรุปการประเมิน) — ข้อความอิสระระดับ Exam card (ไม่ผูกกับปัญหาใดปัญหาหนึ่งโดยเฉพาะ) ใช้สรุปภาพรวมทางคลินิกและแผนติดตาม

Checklist การลงข้อมูล Assessment
  1. เปิดหน้า Assessment จากปุ่มทางลัดในหน้า Exam Card Editor
  2. กด 🔍 เลือก Concept ค้นหาและเลือกปัญหา/ข้อวินิจฉัยที่ต้องการ (หรือกรอกช่อง NOTE ถ้าค้นหาไม่พบ)
  3. กรอก Clinical Condition Category และ Clinical Status ให้ครบ (ฟิลด์บังคับ) พร้อมข้อมูลอื่นตามบริบทเคส
  4. กด Append Problem เพื่อเก็บรายการเข้า Selected Problem / Diagnosis Terms — ทำซ้ำได้หลายปัญหาต่อ 1 Exam card
  5. ตรวจแถบ Required ให้ครบ Concept หรือ Problem Note (อย่างน้อยหนึ่งอย่าง) / Category / Status / DVM / Dept
  6. กรอก Assessment Note สรุปภาพรวม แล้วกด Confirm เพื่อบันทึกลงฐานข้อมูลจริง
