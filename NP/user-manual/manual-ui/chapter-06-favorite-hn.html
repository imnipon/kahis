Chapter 06 — Favorite HN / Manage Favorite OPD

Favorite HN — การค้นหาและจัดการรายการ HN โปรด

ฟีเจอร์นี้ใช้บันทึกรายการ HN ที่ต้องการติดตามบ่อยไว้เป็นรายการโปรด (Favorite) พร้อมจัดกลุ่มด้วยโฟลเดอร์ เพื่อให้ค้นและเข้าถึง Exam card ของสัตว์ป่วยเหล่านั้นได้รวดเร็วขึ้น คลิกที่ภาพเพื่อดูขนาดจริง

ส่วนที่ 1 — ค้นหา HN และเลือกเข้ารายการโปรด

1 เมนูค้นหา HN Search Menu

ขั้นตอนแรก เข้าเมนูค้นหา HN ที่ต้องการ

2 ช่องค้นหา / ตัวกรอง Search / Filter

ใส่หมายเลข HN ที่ต้องการ หรือใช้คำค้นหาอื่น ๆ ตามช่องตัวกรอง

3 ไอคอนเลือกเข้า Favorite Favorite Toggle

icon เพื่อเลือก HN ที่ต้องการใส่ใน favorite — สีขาว คือยังไม่เลือก, สีส้ม คืออยู่ในรายการแล้ว

4 บล็อกรายการ Favorite ที่เลือกแล้ว Favorite Block

บล็อกรายการ favorite ที่เลือกแล้ว ด้านบนเป็นส่วนการสร้างโฟลเดอร์ และการแสดงหรือซ่อนบล็อก favorite

5 ส่วนแสดงรายการ Favorite List

ส่วนแสดงรายการ ซึ่งสามารถลบได้จากไอคอนถังขยะ

  • คลิกที่เลข HN จะเป็นการเลือกรายการ
  • วางเคอร์เซอร์เมาส์บน HN จะแสดง tooltip รายละเอียดเบื้องต้นของ HN นั้น

ส่วนที่ 2 — เพิ่มรายการเข้าโฟลเดอร์ Favorite

เมื่อกดไอคอน Favorite (ส่วนที่ 1 Label 3) เลือก HN ที่ต้องการ ระบบจะเปิดหน้าต่างนี้ให้เลือกโฟลเดอร์ปลายทาง

1 ตรวจสอบ HN ที่เลือก Confirm HN

เมื่อเลือก HN จากรายการค้นหา ให้เริ่มจากการตรวจสอบเลขว่าตรงกับที่ต้องการหรือไม่

2 เลือกโฟลเดอร์ปลายทาง Folder

เลือกโฟลเดอร์ที่ต้องการ หรือเลือก root เพื่อให้รายการไม่ระบุโฟลเดอร์

3 ปุ่ม Add Add

ปุ่ม "add" เพื่อเพิ่มรายการไปที่โฟลเดอร์ที่เลือก

4 รายการที่อยู่ใน Favorite แล้ว Existing / Remove

กรณีเป็นรายการที่อยู่ใน favorite แล้ว จะมีบล็อกแสดงที่อยู่โฟลเดอร์ปัจจุบัน และปุ่ม "ถังขยะ" เพื่อนำออกจากรายการ favorite

แผนที่ส่วนประกอบ — สรุปบทที่ 6 สรุป

ส่วนที่ 1ค้นหา HN — ค้นหา/กรอง แล้วกดไอคอน Favorite (ขาว = ยังไม่เลือก, ส้ม = เลือกแล้ว)

ส่วนที่ 2เลือกโฟลเดอร์ — ยืนยัน HN, เลือกโฟลเดอร์ (หรือ root) แล้วกด Add; ถ้ามีอยู่แล้วกดถังขยะเพื่อนำออก

Checklist การจัดการ Favorite HN
  1. เข้าเมนูค้นหา HN แล้วใส่เลข HN หรือคำค้นที่ต้องการ
  2. กดไอคอน Favorite ที่รายการ HN เพื่อเปิดหน้าต่างเลือกโฟลเดอร์
  3. ตรวจสอบเลข HN ให้ตรง เลือกโฟลเดอร์ปลายทาง (หรือ root) แล้วกด Add
  4. ตรวจดูรายการที่บันทึกแล้วในบล็อก Favorite และลบได้ด้วยไอคอนถังขยะ
