Chapter 01 — UI Overview · VR001

ส่วนประกอบหลักของหน้าจอ Vetroom

ภาพนี้แสดงหน้าจอหลักของระบบ Vetroom ในขั้นตอน S — Subjective + Systematic Exam โดยมี Label หมายเลข 1–7 ชี้ไปยังส่วนประกอบสำคัญของ UI แต่ละส่วน คลิกที่ภาพเพื่อดูขนาดจริง

คำอธิบายแต่ละ Label

1 แถบเมนูนำทางหลัก (Main Navigation Bar) เมนูระบบ

แถบเมนูนำทางหลักสำหรับสลับไปยังโมดูลต่าง ๆ ของระบบ ประกอบด้วย:

  • ค้นหา HN — สำหรับค้นหาแฟ้มสัตว์เลี้ยงที่ต้องการในการทำงาน
  • ลงทะเบียน — เมนูสำหรับแผนกเวชระเบียน สำหรับการทำประวัติสัตว์เลี้ยงและเจ้าของสัตว์ การลงทะเบียนเข้ารับบริการ (Check in) และรายงานประจำวันเบื้องต้น
  • รีเควส — สำหรับเรียกใช้งานฟังก์ชัน "การส่งตรวจ" สำหรับแผนกเฉพาะ เช่น การส่งเอกซเรย์
  • นัดหมาย — สำหรับเรียกใช้งานฟังก์ชัน "ลงข้อมูลการนัดหมาย" การทำนัด และการจัดการรายการนัดหมายในระบบ
  • Board — สำหรับเรียกใช้งานฟังก์ชัน "ตารางรายการลงทะเบียนเพื่อการจัดการการเข้ารับบริการ"
  • Vetroom — สำหรับเรียกใช้งานฟังก์ชัน "การบันทึกข้อมูลการให้บริการตรวจรักษา"
  • การเงิน — สำหรับเรียกใช้งานฟังก์ชัน "การชำระค่าบริการ" สำหรับแผนกการเงิน และรายงานประจำวันเบื้องต้น
  • Rx Center — สำหรับเรียกใช้งานฟังก์ชัน "การดำเนินการจ่ายยานำกลับ" สำหรับแผนกยานำกลับ
  • LAB — สำหรับเรียกใช้งานฟังก์ชัน "การแสดงผลรายงานผลตรวจห้องปฏิบัติการ" (รอการพัฒนา)
  • My Setting — สำหรับเรียกใช้งานฟังก์ชัน "การตั้งค่าการทำงานของ User" สำหรับ user account ที่กำลังเข้าใช้งานปัจจุบัน
  • ตั้งค่า — สำหรับเรียกใช้งานฟังก์ชัน "การตั้งค่าเครื่องปัจจุบัน" สำหรับผู้ดูแลระบบในการ setup ค่าที่เกี่ยวข้องในการบันทึกข้อมูลและการใช้งานของเครื่องปัจจุบันให้ส่งข้อมูลให้เครื่องแม่ข่ายได้ถูกต้อง
  • ผู้ดูแลระบบ — สำหรับเรียกใช้งานฟังก์ชัน "Backend" สำหรับผู้ดูแลระบบ (admin) เพื่อการสร้าง จัดการ ปรับแต่ง และทำรายงานของระบบ
2 ส่วนการจัดการผู้ใช้งาน มุมขวาบน
  • เมนูสลับภาษา — สลับภาษาไทยและอังกฤษสำหรับ UI ของระบบ (อยู่ในช่วงกำลังพัฒนา)
  • ภาพอวาตาร์ (Avatar) ผู้ใช้ — สำหรับเรียกใช้งานฟังก์ชัน "กำหนดแผนกเพื่อใช้ในการบันทึกข้อมูล" และ "การออกจากระบบ"
3 แถบข้อมูลสัตว์เลี้ยงที่เลือก ข้อมูล HN

แสดงข้อมูลสรุปของสัตว์เลี้ยงและเจ้าของที่กำลังทำงานอยู่ ประกอบด้วย:

  • OPD No., Pet Name, Species/Breed, Gender, Age, Blood Type
  • Owner No., Owner Name
4 ส่วนแสดงรายละเอียดการเข้ารับบริการ และทางลัดฟังก์ชัน Visit / Function
  • Visit — แสดงหมายเลข Visit No. ปัจจุบันของ HN นี้ หากเป็นสีเขียวและมีหมายเลขกำกับ แสดงว่าเป็นการทำงาน HN ที่อยู่ในระบบ (เข้าสู่ระบบแล้ว) หากเป็นสีเทาและไม่มีหมายเลขกำกับ แสดงว่าเป็นการทำงาน HN ที่ไม่อยู่ในระบบปัจจุบัน (ออกจากระบบ)
  • Visit Charge — แสดงยอดรวมค่าใช้จ่ายที่เกิดขึ้น (มีการบันทึกแล้ว) ใน Visit No. ปัจจุบัน มีเมนูย่อยเพื่อแสดงรายการในแต่ละรูปแบบย่อยด้วย
  • Function — ทางลัดเข้าสู่ฟังก์ชันที่เกี่ยวข้องกับ HN และ Visit No. ที่เลือกอยู่ เช่น Request, นัดหมาย
5 TAB Menu แท็บเมนูหลัก

ประกอบด้วย 3 ส่วนหลัก:

SOAP — แท็บเมนูส่วนประกอบการบันทึกการตรวจรักษา
  • S = Subjective + Systematic Exam — ทำงานภายใต้ Exam card id เป็นส่วนบันทึกข้อมูลการตรวจทั่วไป และการลงข้อมูลเฉพาะ เช่น VPE (Vital Sign & Physical Examination), Assessment, Order Tx, Rx, LAB, Plan โดยทั้งหมดในการสั่งที่นี่จะทำงานแบบกำกับด้วย Exam card id
  • O = Objective — ส่วนแสดงข้อมูลภาพรวมทั้งหมดในแต่ละ Exam card id
  • A = Assessment — ส่วนการแสดงผลข้อมูลของ Assessment
  • P = Plan — ส่วนการแสดงผลข้อมูลของ Plan
ORDER — แท็บเมนูส่วนประกอบของการสั่งรายการยา เวชภัณฑ์ หัตถการ และค่าบริการต่าง ๆ
  • Order Tx — สำหรับการบันทึกการใช้งานยาและเวชภัณฑ์ และบริการต่าง ๆ ที่เกิดขึ้นในห้องตรวจ (มีการดำเนินการโดยโรงพยาบาลสัตว์)
  • Order Rx — สำหรับการบันทึกการสั่งจ่ายยาและเวชภัณฑ์ และอื่น ๆ ที่นำกลับ (ยังไม่ดำเนินการในโรงพยาบาลสัตว์)
  • Order Lab — สำหรับการบันทึกการสั่งตรวจทางห้องปฏิบัติการ ทางโลหิตวิทยาและปัสสาวะ
  • Order Pathology — สำหรับการบันทึกการสั่งตรวจทางห้องปฏิบัติการพยาธิวิทยา
External Documents

แท็บเมนูสำหรับการนำเข้าเอกสารประกอบการบริการ (ที่ไม่มีส่วนกรอกข้อมูลและแสดงผลภายในแอปพลิเคชัน) และเอกสารจากภายนอกโรงพยาบาลสัตว์ โดยวิธีการสแกนและนำเข้าภาพ หรือไฟล์เอกสารบางประเภท และการแสดงผลข้อมูลที่บันทึกแล้ว

6 แผง History ด้านซ้าย

ส่วนแสดงรายการ Exam card id ที่บันทึกแล้วของ HN ที่เลือกนี้ พร้อมตัวกรองช่วยเรียงหรือค้นหารายการที่ต้องการ

7 พื้นที่รายละเอียด ด้านขวา

ส่วนแสดงเนื้อหาของ Exam card id ที่เลือกจากฝั่ง History ในส่วนของการบันทึกหัวข้อของ Exam card พร้อมภาพประกอบ

  • มีส่วนแสดงภาพแบบ lightbox (ถ้ามีภาพ) และปุ่ม copy ข้อมูลในรูปแบบ Plain text ของเนื้อหา
  • ในแผนพัฒนาจะมีฟังก์ชันการนำเข้าภาพจาก Mobile Phone โดยผ่านทางอินเทอร์เน็ต
  • ส่วนเฉพาะเจ้าหน้าที่ที่ได้รับมอบหมาย (ปัจจุบันเฉพาะผู้ดูแลระบบ) สามารถตรวจสอบประวัติการบันทึก (History Log) และการ Export to Document
แผนที่ส่วนประกอบ UI — สรุป Label 1–7 สรุปบทที่ 1

1แถบเมนูนำทางหลัก — สลับโมดูลระบบ (ค้นหา HN, ลงทะเบียน, Board, Vetroom, LAB ฯลฯ)

2ส่วนการจัดการผู้ใช้งาน — สลับภาษา, กำหนดแผนก, ออกจากระบบ

3แถบข้อมูลสัตว์เลี้ยงที่เลือก — แสดง OPD No., Pet Name, Owner, Gender, Age ฯลฯ

4Visit / Function / Visit Charge — สถานะ visit, ยอดค่าใช้จ่าย, ทางลัดฟังก์ชัน

5TAB Menu — SOAP, ORDER (Tx/Rx/Lab/Pathology), External Documents

6แผง History — รายการ Exam card id ที่บันทึกแล้ว

7พื้นที่รายละเอียด — แสดง/บันทึกเนื้อหา Exam card, ภาพ, Export

Checklist ก่อนเริ่มใช้งาน
  1. ตรวจสอบข้อมูลสัตว์เลี้ยงใน Label 3 ให้ถูกต้อง
  2. ยืนยันสถานะ Visit ใน Label 4 (สีเขียว = อยู่ในระบบ)
  3. เลือกแท็บที่เหมาะสมใน TAB Menu (Label 5)
  4. เลือก Exam card id จากแผง History (Label 6) และ ดูรายละเอียดในพื้นที่รายละเอียด (Label 7)
