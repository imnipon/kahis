Chapter 02 — Exam Card Viewer · VR004

Subjective & Systematic Examination — ประวัติและ Exam Card

ภาพนี้แสดงหน้าจอ Subjective & Systematic Examination Card Viewer โดยมี Label หมายเลข 1–3 ชี้ไปยังประวัติ Exam card, พื้นที่แสดงรายละเอียด และแถบเครื่องมือ Editor คลิกที่ภาพเพื่อดูขนาดจริง

คำอธิบายแต่ละ Label

1 รายการประวัติการบันทึก Exam card History

รายการประวัติการบันทึก Exam card จะมีการแสดงรายละเอียดดังนี้:

  • วันที่ของการตรวจ — วันที่ที่บันทึก Exam card
  • ชื่อสัตวแพทย์ — ผู้บันทึก/กำกับการตรวจของ Exam card
  • แผนก — แผนกที่กำกับการตรวจของ Exam card
  • หมายเลข Exam card id — รหัสอ้างอิงของ Exam card แต่ละรายการ

เลือกแถวในรายการประวัติเพื่อแสดงรายละเอียดทางด้านขวา (Label 2)

2 ส่วนแสดงรายละเอียดของ Exam card ที่เลือก Viewer

ส่วนแสดงรายละเอียดของ Exam card ที่เลือกจากประวัติด้านซ้าย โดยแสดงเป็น Plain text

  • เรียงลำดับตามลำดับหัวข้อของเนื้อหา
  • นำเนื้อหาที่มีการระบุ Remarkable มาไว้ด้านบนก่อน และแสดงพื้นหลังด้วยสีม่วง
  • หัวข้อเนื้อหาที่ไม่มีการระบุ Remarkable จะแสดงตามลำดับปกติ
  • ไม่นำหัวข้อที่ไม่มีข้อมูลมาแสดงผล
3 ส่วนการเรียกหรือสร้าง Exam card ใน Editor Editor

ส่วนการเรียกหรือสร้าง Exam card มาในส่วน Editor ใช้สำหรับการกรอกข้อมูล Plain text ตามหัวข้อของเนื้อหา พร้อมตัวช่วยกรอกในแต่ละหัวข้อ และใส่ภาพประกอบใน Exam card

เครื่องมือส่วนนี้ประกอบด้วย:

เมนู Dropdown วันที่

แสดงวันที่ที่เคยมี Exam card บันทึกไว้ ให้เลือกเพื่อแสดงผล / เรียกเข้า Editor

ปุ่ม Add Exam card

สร้าง Exam card ใหม่ โดยต้องเลือกวันที่ที่ต้องการกำหนดเป็นวันของ Exam card

  • การทำงานปกติ — กดปุ่มเลือก Today (Go to Today) ก่อน แล้วกด Add Exam card
  • การทำงานย้อนหลัง — เลือกวันที่ผ่านมาแล้วผ่านปุ่ม Date Picker หรือเมนู Dropdown ก่อน แล้วจึงกด Add Exam card
ปุ่มเลือกวันที่ (Date Picker)
  • เลือกวันที่ที่ต้องการให้แสดงผล โดยต้องเป็นวันที่อยู่ในช่วงเวลาลงทะเบียนรับบริการเท่านั้น
  • ในปฏิทิน วันที่ที่เลือกได้จะถูกแสดงผล และมีสัญลักษณ์กำกับวันที่มีการบันทึก Exam card ไว้แล้ว
ปุ่ม Full Screen

เปิด Editor ในรูปแบบ Full Screen Mode เพื่อพื้นที่ทำงานที่กว้างขึ้น

แผนที่ส่วนประกอบ — สรุป Label 1–3 สรุปบทที่ 2

1ประวัติ Exam card — วันที่ตรวจ, ชื่อสัตวแพทย์, แผนก, Exam card id

2รายละเอียด Exam card — Plain text, Remarkable (พื้นม่วง) ขึ้นก่อน, ไม่แสดงหัวข้อว่าง

3Exam Card Editor — Dropdown วันที่, Add Exam card, Today, Date Picker, Full Screen

Checklist การใช้งาน Exam Card Viewer / Editor
  1. เลือก Exam card จากประวัติ (Label 1) แล้วตรวจรายละเอียดใน Viewer (Label 2)
  2. ตรวจว่าหัวข้อ Remarkable อยู่ด้านบนและมีพื้นหลังสีม่วง
  3. ก่อนสร้าง Exam card ใหม่: กด Today (กรณีวันปัจจุบัน) หรือเลือกวันที่ผ่าน Date Picker / Dropdown
  4. ยืนยันว่าวันที่อยู่ในช่วงลงทะเบียนรับบริการ ก่อนกด Add Exam card
  5. ใช้ Full Screen เมื่อต้องการพื้นที่ Editor กว้างขึ้น
