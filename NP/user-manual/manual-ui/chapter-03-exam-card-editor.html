Chapter 03 — Subjective & Systematic Examination, Data Entry

Subjective & Systematic Exam Card Editor — การลงข้อมูลและโหมดการแสดงผล

บทนี้อธิบายโหมดการแสดงผลของ Exam Card Editor (Full Screen / Floating / ปิดโหมด) และส่วนประกอบหลักที่ใช้ลงข้อมูลในใบบันทึกการตรวจ คลิกที่ภาพเพื่อดูขนาดจริง

ส่วนที่ 1 — โหมดการแสดงผล Editor

ปุ่มที่ใช้เปลี่ยนโหมดอยู่ที่มุมขวาบนของแถบ Exam Card Editor เลือก Full Screen Mode หรือ Floating Mode ได้ ส่วนปุ่ม X (ปิด) คือการกลับมาแสดงผลตามความยาวของหน้าเพจ ภาพด้านล่างแสดงตัวอย่างการแสดงผลในแต่ละโหมด

1 Full Screen Mode โหมดแสดงผล

ภาพแสดง Editor ในโหมด Full Screen — Editor ขยายเต็มพื้นที่ทำงาน เพื่อให้มีพื้นที่ลงข้อมูลมากขึ้น และยังเห็นแถบเมนูระบบด้านบน

2 Floating Mode โหมดแสดงผล

ภาพแสดง Editor ในโหมด Floating — Editor ลอยทับหน้า Viewer / History ทำให้ยังเห็นประวัติ Exam card และรายละเอียดด้านหลังได้ขณะกรอกข้อมูล เหมาะเมื่อต้องการอ้างอิงข้อมูลที่บันทึกไว้แล้วควบคู่กับการแก้ไข

3 ปิดโหมดด้วยปุ่ม X — กลับแสดงผลตามความยาวหน้า Close

ภาพแสดงผลเมื่อกดปุ่ม X ปิดโหมดขยาย — ระบบกลับมาแสดงผลตามความยาวของหน้าเพจ (หน้าเดียว)

หากมีการแก้ไขที่ยังไม่บันทึก อาจมีสถานะหรือการแจ้งเตือนที่เกี่ยวข้องกับการปิด Editor (รายละเอียดตามพฤติกรรมจริงในระบบ)

ส่วนที่ 2 — ส่วนประกอบของ Exam Card Editor

ใช้ภาพ Full Screen เพื่ออธิบายส่วนประกอบหลักที่ใช้ลงข้อมูลในใบบันทึกการตรวจ

คำอธิบายแต่ละ Label

A แถบข้อมูลผู้บันทึกและวันที่ของ Exam card Header / TAB

แสดงชื่อสัตวแพทย์ แผนก และวันที่ของ Exam card ที่กำลังแก้ไข (เช่น For 28 Aug 2026) รวมถึงสถานะ เช่น NEW เมื่อเป็นใบใหม่

มีได้หลาย TAB ตามข้อกำหนดดังนี้:

  • สัตวแพทย์หนึ่ง user สามารถมี Exam card id เดียวต่อหนึ่งแผนก ในวันที่เลือกแสดงผล — แต่เพิ่มได้ถ้าต่างแผนก
  • แสดง TAB ของ Exam card ทุก id ที่เป็นของวันที่เลือก จากทุก user สัตวแพทย์
  • การแก้ไข ต้องเป็น user สัตวแพทย์ของ Exam card นั้นเท่านั้น — ถ้าไม่ใช่จะสามารถดูเนื้อหาได้เท่านั้น
B การเลือกเปลี่ยนแผนกกำกับ Exam card และปุ่มบันทึก Department / Save

ใช้เลือกหรือเปลี่ยนแผนกที่กำกับ Exam card และปุ่มบันทึกข้อมูล:

  • Add New — เมื่อเป็น Exam card ใหม่ที่ยังไม่เคยบันทึก จะสร้าง Exam card id ให้
  • Apply — เมื่อเป็นการแก้ไขข้อมูลที่เคยบันทึกแล้ว
C รายการ Topics (แถบซ้าย) Topics

รายการหัวข้อเนื้อหาของใบบันทึก เช่น History Taking, Appearance, Heart ฯลฯ

  • คลิกหัวข้อเพื่อเลื่อนไปยังบล็อกกรอกข้อมูลของหัวข้อนั้น
  • มีส่วน Assessment แยกท้ายรายการ ที่เป็นการแสดงผลเท่านั้น
D พื้นที่กรอกเนื้อหา (Plain text) Content

กล่องข้อความสำหรับบันทึกเนื้อหาของแต่ละหัวข้อแบบ Plain text เป็นพื้นที่หลักของการลงข้อมูลตรวจ

E ช่อง Remarkable Remarkable

ทำเครื่องหมายหัวข้อที่สำคัญ เมื่อระบุ Remarkable เนื้อหานั้นจะถูกจัดให้อยู่ด้านบนใน Viewer และแสดงพื้นหลังสีม่วง #F0E4FF

F ตัวช่วยกรอกข้อมูล Helpers

เมนูช่วยกรอกในแต่ละหัวข้อ ประกอบด้วย:

  • My exam template — ใช้เทมเพลตที่บันทึกไว้เอง
  • Guideline — ใช้แนวทาง/ตัวอย่างการบันทึก
  • Order — ทางลัดการสั่งรายการที่เกี่ยวข้องกับหัวข้อ Tx, Rx, Lab, Path โดยการสั่งจากเมนูนี้จะเป็นการสั่งและกำกับการสั่งด้วย Exam card id ที่ทำงานอยู่ด้วย จะมีผลในการแสดงผล Exam card นี้ใน View เมนูต่าง ๆ ด้วย
G ปุ่มทางลัดเข้าหน้าการบันทึกข้อมูลโมดูลอื่น Shortcuts

ปุ่มทางลัดงานร่วมกับการบันทึก Exam card ได้แก่:

  • Vital Sign & PE (VPE)
  • Assessment
  • Plan
  • ปุ่มลบ Exam card id นี้ — โดยแอดมิน
แผนที่ส่วนประกอบ — สรุปบทที่ 3 สรุป

1–3ตัวอย่างโหมดแสดงผล — Full Screen / Floating / ปิดด้วย X กลับหน้าเดียว (ปุ่มมุมขวาบน)

Aผู้บันทึก / วันที่ / TAB — 1 id ต่อแผนกต่อ user; TAB รวมทุก id ของวัน; แก้ได้เฉพาะเจ้าของ

Bแผนก + บันทึก — Add New (สร้าง id) / Apply (แก้ไขที่บันทึกแล้ว)

CTopics — เลือกหัวข้อลงข้อมูล; Assessment ท้ายรายการเป็นแสดงผลอย่างเดียว

DPlain text — พื้นที่กรอกเนื้อหาหลัก

ERemarkable — เน้นหัวข้อสำคัญใน Viewer

Fตัวช่วยกรอก — Template / Guideline / Order (Tx, Rx, Lab, Path กำกับด้วย Exam card id)

Gทางลัดโมดูลอื่น — VPE / Assessment / Plan / ลบ Exam card (แอดมิน)

Checklist การลงข้อมูลในใบบันทึกการตรวจ
  1. เลือกโหมดแสดงผลที่มุมขวาบน (Full Screen หรือ Floating) หรือกด X เพื่อกลับหน้าเดียว
  2. ตรวจวันที่ Exam card และ TAB ให้ตรงกับแผนก/user ที่ต้องการ — แก้ไขได้เฉพาะ Exam card ของตนเอง
  3. ถ้าเป็นใบใหม่: เลือกแผนกแล้วกด Add New; ถ้าเคยบันทึกแล้วใช้ Apply
  4. กรอกทีละหัวข้อจาก Topics และใช้ตัวช่วยกรอก (Template / Guideline / Order) เมื่อจำเป็น
  5. ทำเครื่องหมาย Remarkable เฉพาะหัวข้อที่ต้องการเน้นใน Viewer
  6. ใช้ทางลัด VPE / Assessment / Plan ตามงาน และบันทึกก่อนปิด Editor เมื่อมีข้อมูลสำคัญ
