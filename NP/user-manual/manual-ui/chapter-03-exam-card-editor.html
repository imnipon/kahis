Chapter 03 — Subjective & Systematic Examination, Data Entry

Subjective & Systematic Exam Card Editor — การลงข้อมูลและโหมดการแสดงผล

บทนี้อธิบายโหมดการแสดงผลของ Exam Card Editor (Full Screen / Floating / ปิดโหมด) และส่วนประกอบหลักที่ใช้ลงข้อมูลในใบบันทึกการตรวจ คลิกที่ภาพเพื่อดูขนาดจริง

ส่วนที่ 1 — โหมดการแสดงผล Editor

ปุ่มเปลี่ยนโหมดอยู่ที่มุมขวาบนของแถบ Exam Card Editor โดยวนไอคอนเพื่อสลับระหว่าง Full Screen, Floating และการปิดโหมดกลับหน้าเดียวตามความยาวเพจ

1 ปุ่มเปลี่ยนโหมดการแสดงผล — Full Screen Full Screen

ใช้สลับโหมดการแสดงผลของ Exam Card Editor โดยวนไอคอนตามลำดับ เช่น Full Screen → Floating → ปิดโหมด (กลับหน้าเดียวตามความยาวเพจ)

ในโหมด Full Screen Editor จะขยายเต็มพื้นที่ทำงาน เพื่อให้มีพื้นที่ลงข้อมูลมากขึ้น และยังเห็นแถบเมนูระบบด้านบน

2 ปุ่มเปลี่ยนโหมดการแสดงผล — Floating Floating

ในโหมด Floating Editor จะลอยทับหน้า Viewer / History ทำให้ยังเห็นประวัติ Exam card และรายละเอียดด้านหลังได้ขณะกรอกข้อมูล

เหมาะเมื่อต้องการอ้างอิงข้อมูลที่บันทึกไว้แล้วควบคู่กับการแก้ไข

3 ปุ่มเปลี่ยนโหมด / ปิด Editor Close

เมื่อปิดโหมดขยายหรือปิด Editor ระบบจะกลับไปแสดงผลแบบหน้าเดียวตามความยาวของหน้าเพจ

หากมีการแก้ไขที่ยังไม่บันทึก อาจมีสถานะหรือการแจ้งเตือนที่เกี่ยวข้องกับการปิด Editor (รายละเอียดตามพฤติกรรมจริงในระบบ)

ส่วนที่ 2 — ส่วนประกอบของ Exam Card Editor

ใช้ภาพ Full Screen เพื่ออธิบายส่วนประกอบหลักที่ใช้ลงข้อมูลในใบบันทึกการตรวจ

คำอธิบายแต่ละ Label

A แถบข้อมูลผู้บันทึกและวันที่ของ Exam card Header

แสดงชื่อสัตวแพทย์ แผนก และวันที่ของ Exam card ที่กำลังแก้ไข (เช่น For 28 Aug 2026) รวมถึงสถานะ เช่น NEW เมื่อเป็นใบใหม่

B แผนกและการเพิ่มรายการที่เกี่ยวข้อง Department

เลือกแผนกที่ใช้กำกับการบันทึก และปุ่ม Add New (รวมถึงเมนูเพิ่มเติมถ้ามี) สำหรับงานเสริมที่เกี่ยวกับ Exam card

C รายการ Topics (แถบซ้าย) Topics

รายการหัวข้อเนื้อหาของใบบันทึก เช่น History Taking, Appearance, Heart ฯลฯ

  • คลิกหัวข้อเพื่อเลื่อนไปยังบล็อกกรอกข้อมูลของหัวข้อนั้น
  • มีส่วน Assessment แยกท้ายรายการ
D พื้นที่กรอกเนื้อหา (Plain text) Content

กล่องข้อความสำหรับบันทึกเนื้อหาของแต่ละหัวข้อแบบ Plain text เป็นพื้นที่หลักของการลงข้อมูลตรวจ

E ช่อง Remarkable Remarkable

ทำเครื่องหมายหัวข้อที่สำคัญ เมื่อระบุ Remarkable เนื้อหานั้นจะถูกจัดให้อยู่ด้านบนใน Viewer และแสดงพื้นหลังสีม่วง #F0E4FF

F ตัวช่วยกรอกข้อมูล Helpers

เมนูช่วยกรอกในแต่ละหัวข้อ ประกอบด้วย:

  • My exam template — ใช้เทมเพลตที่บันทึกไว้เอง
  • Guideline — ใช้แนวทาง/ตัวอย่างการบันทึก
  • Order — ทางลัดการสั่งรายการที่เกี่ยวข้องกับหัวข้อ
G แถบเครื่องมือ Editor Block Editor Tools

ปุ่มทางลัดงานร่วมกับการบันทึก Exam card เช่น Vital Sign, Create Assessment, Add Plan และเครื่องมือจัดการอื่นในแถบเดียวกัน

แผนที่ส่วนประกอบ — สรุปบทที่ 3 สรุป

1–3ปุ่มเปลี่ยนโหมด — Full Screen / Floating / ปิดโหมดกลับหน้าเดียว

Aแถบผู้บันทึกและวันที่ — สัตวแพทย์, แผนก, วันที่ Exam card

Bแผนก / Add New — กำหนดแผนกและงานเสริม

CTopics — เลือกหัวข้อเพื่อลงข้อมูล

DPlain text — พื้นที่กรอกเนื้อหาหลัก

ERemarkable — เน้นหัวข้อสำคัญใน Viewer

Fตัวช่วยกรอก — Template / Guideline / Order

GEditor Block — Vital Sign / Assessment / Plan

Checklist การลงข้อมูลในใบบันทึกการตรวจ
  1. เปิด Editor และเลือกโหมดที่เหมาะสม (Full Screen หรือ Floating)
  2. เลือกวันที่ Exam card ให้ถูกต้องก่อนลงข้อมูล
  3. กรอกทีละหัวข้อจาก Topics และใช้ตัวช่วยกรอกเมื่อจำเป็น
  4. ทำเครื่องหมาย Remarkable เฉพาะหัวข้อที่ต้องการเน้นใน Viewer
  5. บันทึกก่อนปิด Editor หรือเปลี่ยนโหมดเมื่อมีข้อมูลสำคัญ
