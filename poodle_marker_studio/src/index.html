❓ คำถามที่พบบ่อย (FAQ)
🔒 รูปภาพถูกส่งขึ้นเน็ตหรือไม่?▾
ไม่เลย — ทุกอย่างทำงานในเบราว์เซอร์บนเครื่องคุณ 100% Offline รูปและข้อมูล autosave เก็บใน IndexedDB ของ browser
🔢 Num Label / Text Label ใช้อย่างไร?▾
เลือกเครื่องมือ → คลิกบนภาพเพื่อวาง ระบบรันลำดับ 1,2,3... หรือ A,B,C... อัตโนมัติ ตั้งเลข/ตัวอักษรเริ่มต้นและรีเซ็ตได้ในแถบซ้าย
📝 Textbox (Tt) กับภาษาไทย?▾
ใช้ IBM Plex Sans Thai Looped ตัดคำอัตโนมัติด้วย Intl.Segmenter — ลากขยายกล่องแล้วข้อความ wrap ถูกต้อง ไม่ตัดกลางคำ
✏️ Description คืออะไร?▾
คำอธิบายเพิ่มเติมใน Edit Modal — พิมพ์ได้หลายบรรทัด ไม่แสดงบนภาพ ใช้เก็บเนื้อหาสำหรับ Export Marker และส่งต่อ AI สร้างคู่มือ รายการที่มี Description จะมีไอคอน 📝 ในแถบขวา
↕️ จัดลำดับรายการอย่างไร?▾
ใช้ปุ่ม ↑ ↓ ในแถบรายการ Marker ด้านขวา เลขลำดับด้านหน้า (1, 2, 3...) คือลำดับในคู่มือ ลำดับนี้บันทึกใน autosave, Export Marker และ Export Project
💾 Last autosave / งานค้างคืออะไร?▾
ระบบบันทึกอัตโนมัติทุก ~3 วินาทีใน IndexedDB แสดงเวลา Last autosave HH:mm:ss บน topbar เปิดแอปใหม่จะถามโหลดงานค้าง — ภาพใหญ่มากอาจบันทึกเฉพาะ markers
📤 Export ภาพ / Marker / Project ต่างกันอย่างไร?▾
Export ภาพ — ไฟล์ PNG/JPEG/WEBP มี markers บนภาพ
Export Marker — JSON/Markdown รายการ+Description+ลำดับ (ส่ง AI)
Export Project — .poodle.json ครบภาพ+markers (backup/ย้ายเครื่อง)
เปิด/แก้ไข Project — โหลด .poodle.json กลับมาทำต่อ
💻 ย้ายงานไปเครื่องอื่นได้ไหม?▾
ได้ — กด Export Project แล้ว copy ไฟล์ .poodle.json ไปเครื่องใหม่ เปิดแอป → เปิด/แก้ไข Project งานกลับมาครบ รวมลำดับและ Description
🤖 ส่ง AI สร้างคู่มืออย่างไร?▾
1) จัดลำดับรายการด้วย ↑↓ และใส่ Description 2) Export ภาพ + Export Marker (JSON หรือ Markdown) 3) แนบทั้งสองให้ AI พร้อมบอกให้ใช้ index เป็นหัวข้อและ description เป็นเนื้อหา
💾 Export ภาพ ได้ความละเอียดเท่าต้นฉบับ?▾
ใช่ — Export เรนเดอร์ที่ความละเอียดต้นฉบับ 100% เสมอ ไม่ขึ้นกับ zoom บนหน้าจอ
📂 Save As dialog ไม่ขึ้น?▾
Save As ทำงานบน localhost/HTTPS ถ้าเปิดผ่าน file:// ไฟล์จะ download อัตโนมัติแทน — ใช้ Live Server หรือ npx serve ได้
🎨 สี Last (custom) คืออะไร?▾
เมื่อเลือกสีจาก Color Picker ที่ไม่ใช่ preset จะเก็บเป็น dot ขอบประ (สีล่าสุด) ใช้ซ้ำได้ทั้งแถบซ้ายและ Edit Modal
👆 Select / ลบ / สำเนา / ล้างทั้งหมด?▾
เลือกเครื่องมือ Select แล้วคลิกชิ้นงาน — ใช้แถบลอยด้านล่าง แก้ไข / สำเนา / ลบ หรือปุ่ม ลบที่เลือก / ล้างทั้งหมด ในแถบซ้าย กด Delete ลบที่เลือกได้
👁️ ซ่อน Marker บนภาพได้ไหม?▾
ได้ — กดไอคอน 👁️ ในแถบรายการด้านขวา Marker จะไม่แสดงบนภาพ แต่ยังอยู่ในรายการและ Export Marker / Project
⚠️ ภาพใหญ่ autosave จำกัดอย่างไร?▾
ภาพ ~8 MB ขึ้นไป ระบบแจ้งเตือนว่า autosave อาจช้า · ภาพ ~25 MB ขึ้นไป บันทึกเฉพาะ markers (ไม่เก็บภาพใน IndexedDB) — ใช้ Export Project สำรองภาพใหญ่
📖 เปิดคู่มืออยู่ที่ไหน?▾
กดปุ่ม คู่มือ ข้างชื่อ "Poodle Marker Studio" มุมซ้ายบน — มี 15 หัวข้อครอบคลุมทุกฟังก์ชัน

การเปิดรูปภาพ

📂
Browse — คลิกปุ่ม "เลือกรูปภาพ" หรือกดปุ่ม Browse ตรงกลางหน้าจอ แล้วเลือกไฟล์รูปจากเครื่อง
🖱️
Drag & Drop — ลากไฟล์รูปจาก File Explorer มาวางที่กรอบตรงกลางหน้าจอได้โดยตรง
📋
Ctrl+V Paste — กด Ctrl+C ก๊อปภาพจากที่ใดก็ได้ แล้วกด Ctrl+V ในหน้าแอพเพื่อวางทันที
💡 รองรับ PNG, JPG, JPEG, WEBP, GIF, BMP ทุกขนาด
📖 กดปุ่ม คู่มือ ข้างชื่อแอพ (มุมซ้ายบน) เปิดคู่มือฉบับเต็มได้ทุกเมื่อ
🧭 Topbar: Last autosave · Undo/Redo · เปลี่ยนภาพ · เปิด/แก้ไข Project · Export Project · Export Marker · Export ภาพ
2

เครื่องมือ Num Label 1,2,3

1
คลิกปุ่ม 1,2,3 Num Label ในแถบเครื่องมือด้านซ้าย เมาส์จะเปลี่ยนเป็น crosshair
2
คลิกบนตำแหน่งที่ต้องการบนภาพ — วงกลมตัวเลขจะปรากฏและรันลำดับอัตโนมัติ (1, 2, 3...)
3
ตั้งค่าได้ในแถบซ้าย: เลขเริ่มต้น, ขนาด Marker, สีพื้นหลัง (BG), สีตัวเลข (Font)
🔄
กด รีเซ็ต เพื่อเริ่มนับใหม่จากตัวเลขเริ่มต้น ใช้สำหรับสร้างชุดลำดับแยกกัน
3

เครื่องมือ Text Label A,B,C

A
คลิก A,B,C Text Label แล้วคลิกบนภาพ — วงกลมตัวอักษรจะปรากฏรันลำดับ A, B, C, D...
⚙️
เลือกอักษรเริ่มต้นได้จาก Dropdown (A–H) และกด รีเซ็ต เพื่อเริ่มใหม่
💡 Num Label และ Text Label มีลำดับแยกจากกัน สามารถใช้คู่กันบนภาพเดียวได้
4

เครื่องมือ Textbox Tt

1
คลิก Tt Textbox แล้วคลิกบนภาพ — กล่องข้อความจะปรากฏพร้อมให้พิมพ์ทันที
2
พิมพ์ข้อความภาษาไทยหรืออังกฤษ ฟอนต์ IBM Plex Sans Thai Looped พร้อมตัดคำภาษาไทยอัตโนมัติ
↔️
ปรับขนาดกล่องพื้นหลัง — ลากขอบกล่องข้อความเพื่อขยาย/หดความกว้าง กรอบสีพื้นหลังและข้อความจะ wrap ตัดคำตามขนาดกล่องพอดี (ขนาดตัวอักษรไม่เปลี่ยน)
🔤
ปรับขนาดตัวอักษร (Font Size) — ปรับได้ผ่าน Slider ในแถบซ้ายหรือใน Edit Modal
📐
การจัดชิดข้อความ — เลือกจัดชิดซ้าย (⬅), กึ่งกลาง (↔), หรือชิดขวา (➡) ได้จากแถบซ้ายหรือ Edit Modal
🎨
สีพื้นหลัง = สีกรอบกล่อง (มีระยะขอบในโค้งมน ป้องกันสระบน-ล่างล้น) / สีตัวอักษร = สีข้อความ
5

เครื่องมือ Rectangle 🏠

1
คลิก 🏠 Rectangle แล้ว คลิกลาก บนภาพเพื่อวาดกรอบสี่เหลี่ยม
2
สีพื้นหลัง (BG) = สีโปร่งแสงภายในกรอบ / สี Font/Line = สีเส้นขอบ กำหนดจากแถบซ้าย
3
ความหนาเส้นปรับได้ผ่าน Slider "Stroke Width" ในแถบซ้าย

Select, Pan และ Zoom

👆
Select — เลือก ย้าย หรือปรับขนาดชิ้นงาน ใช้แถบลอยด้านล่างเพื่อ แก้ไข / ทำสำเนา / ลบ
📋
ทำสำเนา — เลือกชิ้นงานแล้วกด สำเนา ในแถบลอย หรือแถบซ้าย (ลบที่เลือก / ล้างทั้งหมด อยู่ด้านล่างแถบซ้าย)
✋
Pan — ปุ่ม Pan ใต้ canvas หรือ Space+ลาก เลื่อนมุมมองโดยไม่ขยับ marker
🔍
Zoom — ปุ่ม + / − / Fit / 100% หรือ Ctrl+ล้อเมาส์
🖼️
เปลี่ยนภาพ — บน topbar โหลดภาพใหม่ (confirm ถ้ามี markers)
7

การตั้งค่าสี

🎨
สีพื้นหลัง (BG / Fill) — สีวงกลม Marker / สีกล่อง Textbox / สีพื้นใน Rectangle
✏️
สีตัวอักษร / เส้น (Font / Line) — สีตัวเลข/ตัวอักษรใน Marker / สีข้อความ Textbox / สีขอบ Rectangle
🎯
คลิก Color Dot เลือกสีด่วน หรือ Color Picker เลือกสี custom
⭕
สีล่าสุด (Last) — dot ขอบประ เก็บสี custom ใช้ซ้ำได้ในแถบซ้ายและ Edit Modal
💡 แถบซ้ายมีผลชิ้นใหม่ — ชิ้นเดิมแก้ใน Edit Modal (preset + Last color เหมือนกัน)
