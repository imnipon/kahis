❓ คำถามที่พบบ่อย (FAQ)
🔒 รูปภาพถูกส่งขึ้นเน็ตหรือไม่?▾
ไม่เลยครับ! ทุกอย่างทำงานใน RAM ของเบราว์เซอร์ในเครื่องคุณเท่านั้น 100% Private
🔢 Num Label / Text Label ใช้อย่างไร?▾
คลิกเลือกเครื่องมือ → คลิกบนภาพเพื่อวาง ระบบรันลำดับให้อัตโนมัติ ตั้งค่าเริ่มต้นหรือรีเซ็ตได้ในแถบซ้าย
📝 Textbox (Tt) กับภาษาไทย?▾
ฝัง IBM Plex Sans Thai Looped พร้อมตัดคำอัตโนมัติด้วย Intl.Segmenter — resize กล่องแล้วคำจะ wrap ถูกต้อง ไม่ตัดกลางคำ
✏️ แก้ไขชิ้นงานที่วางแล้วทำอย่างไร?▾
ดับเบิ้ลคลิกที่ชิ้นงานบนภาพ หรือกดไอคอน ✏️ ในแถบขวา เพื่อเปิด Edit Modal ปรับข้อความ ขนาด และสีได้
💾 Export ภาพ ได้ความละเอียดเท่าต้นฉบับ?▾
ใช่ครับ Export จะเรนเดอร์ที่ความละเอียดต้นฉบับ 100% เสมอ ไม่ขึ้นกับ zoom level ในหน้าจอ
📂 Save As dialog ไม่ขึ้น?▾
Save As dialog ทำงานบน Secure Context (localhost/HTTPS) หากเปิดผ่าน file:// ไฟล์จะ download อัตโนมัติแทน ยังใช้งานได้ครับ

คู่มือการใช้งาน Poodle Marker Studio

1

การเปิดรูปภาพ

📂
Browse — คลิกปุ่ม "เลือกรูปภาพ" หรือกดปุ่ม Browse ตรงกลางหน้าจอ แล้วเลือกไฟล์รูปจากเครื่อง
🖱️
Drag & Drop — ลากไฟล์รูปจาก File Explorer มาวางที่กรอบตรงกลางหน้าจอได้โดยตรง
📋
Ctrl+V Paste — กด Ctrl+C ก๊อปภาพจากที่ใดก็ได้ แล้วกด Ctrl+V ในหน้าแอพเพื่อวางทันที
💡 รองรับไฟล์ PNG, JPG, JPEG, WEBP, GIF, BMP ทุกขนาด
2

เครื่องมือ Num Label 1,2,3

1
คลิกปุ่ม 1,2,3 Num Label ในแถบเครื่องมือด้านซ้าย เมาส์จะเปลี่ยนเป็น crosshair
2
คลิกบนตำแหน่งที่ต้องการบนภาพ — วงกลมตัวเลขจะปรากฏและรันลำดับอัตโนมัติ (1, 2, 3...)
3
ตั้งค่าได้ในแถบซ้าย: เลขเริ่มต้น, ขนาด Marker, สีพื้นหลัง (BG), สีตัวเลข (Font)
🔄
กด รีเซ็ต เพื่อเริ่มนับใหม่จากตัวเลขเริ่มต้น ใช้สำหรับสร้างชุดลำดับแยกกัน
3

เครื่องมือ Text Label A,B,C

A
คลิก A,B,C Text Label แล้วคลิกบนภาพ — วงกลมตัวอักษรจะปรากฏรันลำดับ A, B, C, D...
⚙️
เลือกอักษรเริ่มต้นได้จาก Dropdown (A–H) และกด รีเซ็ต เพื่อเริ่มใหม่
💡 Num Label และ Text Label มีลำดับแยกจากกัน สามารถใช้คู่กันบนภาพเดียวได้
4

เครื่องมือ Textbox Tt

1
คลิก Tt Textbox แล้วคลิกบนภาพ — กล่องข้อความจะปรากฏพร้อมให้พิมพ์ทันที
2
พิมพ์ข้อความภาษาไทยหรืออังกฤษ ฟอนต์ IBM Plex Sans Thai Looped พร้อมตัดคำภาษาไทยอัตโนมัติ
↔️
ปรับขนาดกล่องพื้นหลัง — ลากขอบกล่องข้อความเพื่อขยาย/หดความกว้าง กรอบสีพื้นหลังและข้อความจะ wrap ตัดคำตามขนาดกล่องพอดี (ขนาดตัวอักษรไม่เปลี่ยน)
🔤
ปรับขนาดตัวอักษร (Font Size) — ปรับได้ผ่าน Slider ในแถบซ้ายหรือใน Edit Modal
📐
การจัดชิดข้อความ — เลือกจัดชิดซ้าย (⬅), กึ่งกลาง (↔), หรือชิดขวา (➡) ได้จากแถบซ้ายหรือ Edit Modal
🎨
สีพื้นหลัง = สีกรอบกล่อง (มีระยะขอบในโค้งมน ป้องกันสระบน-ล่างล้น) / สีตัวอักษร = สีข้อความ
5

เครื่องมือ Rectangle 🏠

1
คลิก 🏠 Rectangle แล้ว คลิกลาก บนภาพเพื่อวาดกรอบสี่เหลี่ยม
2
สีพื้นหลัง (BG) = สีโปร่งแสงภายในกรอบ / สี Font/Line = สีเส้นขอบ กำหนดจากแถบซ้าย
3
ความหนาเส้นปรับได้ผ่าน Slider "Stroke Width" ในแถบซ้าย
6

การตั้งค่าสี (สำหรับรายการใหม่)

🎨
สีพื้นหลัง (BG / Fill) — สีวงกลม Marker / สีกล่อง Textbox / สีพื้นใน Rectangle
✏️
สีตัวอักษร / เส้น (Font / Line) — สีตัวเลข/ตัวอักษรใน Marker / สีข้อความ Textbox / สีขอบ Rectangle
🎯
คลิก Color Dot เพื่อเลือกสีด่วน หรือคลิก กล่องสีด้านขวา เพื่อเปิด Color Picker เต็มรูปแบบ
💡 ตั้งค่าสีจะมีผลกับชิ้นงานที่วางใหม่เท่านั้น ชิ้นเดิมต้องแก้ผ่าน Edit Modal
7

การแก้ไขชิ้นงานที่วางแล้ว

🖱️
ดับเบิ้ลคลิก ที่ชิ้นงานบนภาพ — เปิด Edit Modal ได้ทันที
✏️
คลิกไอคอน ดินสอ (✏️) ในรายการ Marker แถบขวา
👆
หรือ เปลี่ยนเครื่องมือเป็น Select (👆) แล้วคลิกชิ้นงาน จากนั้นกดปุ่ม แก้ไข ในแถบลอย
↔️
ใน Edit Modal: แก้ไขข้อความ, ขนาด, สีพื้นหลัง, สีตัวอักษร กด บันทึก เพื่อยืนยัน
8

แถบรายการ Marker (แถบขวา)

👁️
Eye icon — คลิกเพื่อซ่อน/แสดงชิ้นงานบนภาพ (ไม่ลบ ยังอยู่ใน Export)
✏️
Pencil icon — เปิด Edit Modal เพื่อแก้ไขคุณสมบัติของชิ้นนั้น
🗑️
Trash icon — ลบชิ้นงานออกจากภาพ (สามารถ Undo ได้)
📋
คลิกที่การ์ด — เลือกชิ้นงานนั้นบน canvas
9

Undo / Redo และ Keyboard Shortcuts

Ctrl+Zย้อนกลับ (Undo)
Ctrl+Y หรือ Ctrl+Shift+Zทำซ้ำ (Redo)
Delete หรือ Backspaceลบชิ้นงานที่เลือก
Escapeยกเลิกการเลือก / เปลี่ยนเป็น Select tool
Space + ลากPan เลื่อนมุมมองชั่วคราว
Ctrl + เลื่อนล้อเมาส์Zoom เข้า/ออก
10

Export ภาพ

1
กดปุ่ม 🦴 Export ภาพ มุมขวาบน — เปิดหน้าต่าง Export
2
ตั้งชื่อไฟล์ (Default: ชื่อเดิม 10 ตัว + วันเวลา) เลือกรูปแบบ PNG / JPEG / WEBP
3
กด บันทึก / ดาวน์โหลด — ระบบจะ Save As dialog (บน localhost) หรือ download อัตโนมัติ
📐
ภาพที่ Export มีความละเอียด เท่าต้นฉบับ 100% เสมอ ไม่ว่า zoom จะอยู่ที่ระดับใด
⚠️ Save As dialog ไม่ขึ้น? เกิดจากเบราว์เซอร์บล็อก file:// protocol
แก้ไข: ใช้ VS Code Live Server หรือ Node.js ง่ายๆ:
